## Uso del Laboratorio
Este Pixel 6 será utilizado exclusivamente como dispositivo de pruebas para estudiar:

- instalación de GrapheneOS
- funcionamiento del bootloader
- proceso de desbloqueo y bloqueo
- Verified Boot
- cifrado del dispositivo
- aislamiento de aplicaciones
- perfiles de usuario
- configuración de red y VPN
- procedimientos de recuperación y reinstalación
